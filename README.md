# Kleopatra Portable

GPG GUI Client from [KDE](https://apps.kde.org/kleopatra/) specifically [gpg4win](https://gpg4win.org/index.html)'s distribution. GnuPG is not included the only supported distribution is [GPG Plugin by PortableApps.com](https://portableapps.com/apps/security/gpg-plugin-portable) put it in App\GnuPG
